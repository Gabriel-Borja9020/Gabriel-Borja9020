## Sobre mí

Soy estudiante de Computación y actualmente estoy construyendo mis fundamentos en programación y sistemas.

No me considero un experto. Estoy en una etapa de aprendizaje en la que prefiero entender cómo funcionan las cosas y construir proyectos pequeños antes que simplemente aprender herramientas de memoria.

Algunas de las cosas que me interesan:

- Programación y desarrollo de software
- C++ y fundamentos de programación
- Linux y administración de sistemas
- Git y GitHub
- Desarrollo web
- Sistemas operativos y hardware
- Software libre y código abierto
- Aprender nuevos lenguajes de programación

También estoy trabajando en mejorar mi inglés y, a largo plazo, quiero ampliar considerablemente mi conocimiento de lenguajes y tecnologías.
